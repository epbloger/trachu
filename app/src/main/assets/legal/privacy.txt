# Политика конфиденциальности ТРАЧУ.

Редакция: 26 ноября 2026 г. Разработчик: Moorkis Development. Контакт: helpmoorkis@yandex.ru.

ТРАЧУ. — приложение самостоятельного учёта финансов. Оно не предоставляет банковских услуг и не требует регистрации. Приложение не имеет собственного сервера для хранения пользовательских финансовых данных.

## Данные на устройстве

Введённые пользователем счета, суммы, даты, категории, комментарии, теги, изображения чеков, бюджеты, цели, долги, расписания и курсы сохраняются в приватной области приложения. Настройки и защищённый верификатор PIN хранятся локально. Мы не получаем эти сведения автоматически и не отправляем их на серверы разработчика. Пользователь самостоятельно определяет содержание записей.

При включённом PIN применяется проверка PIN, сильная биометрия по выбору и автоблокировка. Биометрические шаблоны контролирует Android; приложение не получает отпечатки или изображение лица. PIN защищает интерфейс; локальная база использует системную изоляцию Android. Зашифрованная резервная копия защищена отдельным паролем. При потере пароля восстановить её невозможно.

## Сетевые обращения

Основные функции доступны без сети. По явной команде «Получить официальные курсы ЦБ РФ» приложение отправляет HTTPS-запрос на www.cbr.ru к публичному сервису курсов с выбранной датой. Если пользователь отдельно включает автоматическое обновление (по умолчанию выключено), приложение запрашивает текущую дату примерно раз в сутки при наличии сети; выключение настройки отменяет будущие фоновые запросы. Финансовые операции, названия счетов, суммы, чеки, идентификаторы записей и PIN не передаются в запросах курсов. Сервер и сетевые посредники могут обрабатывать IP-адрес и обычные технические сведения запроса согласно своим правилам. [Сайт Банка России](https://www.cbr.ru/).

## Реклама и сторонние сервисы

Приложение включает SDK Yandex Mobile Ads. В отладочной сборке используется только официальный демонстрационный рекламный блок. В обычной сборке реклама по умолчанию выключена: SDK не инициализируется и рекламные запросы не выполняются, пока издатель не настроит собственный рекламный блок и явно не включит его для релиза.

В версии с включённой рекламой небольшой баннер показывается только на экране обзора после разблокировки. На экране ввода/редактирования финансовых операций, при просмотре деталей и на экране PIN рекламы нет. Перед инициализацией SDK приложение сообщает отсутствие согласия на персонализацию и отключает отслеживание местоположения; разрешение на рекламный идентификатор Android (AD_ID) исключено из манифеста приложения. Приложение не определяет возраст пользователя и не передаёт SDK возрастные сведения; перед показом рекламы несовершеннолетней аудитории издатель должен проверить применимые возрастные требования.

При включённом SDK Яндекс и его инфраструктура могут самостоятельно обрабатывать IP-адрес, данные устройства и приложения, сетевые идентификаторы, сведения о запросах, показах и взаимодействиях с рекламой, технические диагностические данные для доставки, защиты и измерения рекламы. Объём и сроки такой обработки определяет политика Яндекса: https://yandex.ru/legal/confidential/. Разработчик не добавляет к рекламным запросам суммы, названия счетов, содержимое чеков, категории операций, PIN и финансовую историю. Отсутствие такого прикладного наполнения не означает отсутствие технической обработки данных сторонним SDK. При публикации сборки с рекламой необходимо отдельно проверить реальные потоки данных и декларации магазина.

Банковских интеграций, фоновой отправки финансовых записей разработчику и удалённого профиля нет.

## Файлы и уведомления

Пользователь выбирает файл или место сохранения системным интерфейсом Android. Резервная копия шифруется паролем. CSV и PDF не шифруются и могут содержать финансовую информацию; CSV ТРАЧУ. также содержит связанные записи и чеки. Если пользователь выбирает облачный файловый провайдер, он поручает этому провайдеру хранение файла и применяются его правила. Приложение не имеет доступа ко всему хранилищу и не запрашивает отдельное разрешение на его чтение. Автоматическое системное резервное копирование данных приложения отключено.

Уведомления об обязательствах и бюджетах включаются с разрешения пользователя, содержат общие формулировки. При включённой защите баланс виджета скрывается. WorkManager выполняет локальные фоновые задачи; его системные разрешения используются для планирования и возобновления работы.

## Разрешения

INTERNET — получение публичных валютных курсов по команде или при отдельно включённом обновлении, а при настройке рекламы — запросы Yandex Mobile Ads; POST_NOTIFICATIONS — напоминания (Android 13+); USE_BIOMETRIC/USE_FINGERPRINT — системная биометрия. Рекламный SDK может добавлять собственные технические разрешения, которые нужно проверить в итоговом merged manifest. Разрешение AD_ID удалено из итогового манифеста явным правилом объединения. Системные разрешения фоновой библиотеки WorkManager используются для локальных задач. Приложение не запрашивает геолокацию, SMS, контакты, микрофон, прямой доступ к камере, банковские учётные данные или полный доступ к файлам.

## Управление и удаление

Пользователь может редактировать и удалять записи в приложении, сохранять копии, восстановить выбранную копию или удалить все локальные данные через настройки Android. При удалении приложения приватная база и настройки удаляются системой; самостоятельно сохранённые файлы необходимо удалить отдельно. При обращении в поддержку пользователь сам решает, какую информацию сообщать; не отправляйте чеки, PIN, пароли, реквизиты и финансовую историю. Полученное обращение используется для ответа и решения проблемы.

Политика относится к фактической реализации приложения. При изменении обработки данных она подлежит обновлению до публикации новой версии.
