# Проверка готовности

Состояние кандидата 1.0.0: Android-код `55a0d20`, [95 успешных автоматизированных тестов, артефакты и офлайн-проверка](QA_REPORT.md). Сборка, проверка разрешений, Lint, API 26/33/36 и сохранение суммы после холодного перезапуска подтверждены. Публикация и физические испытания не подтверждены. Проверка сохранённых доказательств без пересборки завершилась успешно в [#45804081213](https://github.com/epbloger/trachu/actions/runs/45804081213); новые изменения Android-кода проходят обычный полный CI.

| Проверка | Критерий |
|---|---|
| JVM-тесты | суммы, перевод, возврат, валюты, бюджет, долг, расписание, CSV, backup |
| Android-тесты | атомарность Room, восстановление, миграция 1→2, реальная запись через Compose |
| Интерфейс | телефон и широкий экран, поворот, навигация, масштабирование |
| Сборка | assembleDebug, bundleRelease, lintDebug, тесты |
| Безопасность | неверный пароль и испорченная копия, PIN/биометрия на физическом устройстве |
| Файлы | SAF, CSV/PDF, фото чеков, перенос между устройствами |
| Сеть | установленный APK без default network: счёт, расход, холодный перезапуск, сверка SQLite; реальный HTTPS-запрос ЦБ; отсутствие запросов рекламы в release без настроенного рекламного блока; сетевые вызовы Яндекса при включённой рекламе |
| Фон | уведомления по разрешению, расписания, повторные запуски |
| Виджет | добавление на launcher, разные размеры, быстрый ввод, скрытие баланса |
| Публикация | подписанный артефакт, реальные скриншоты, анкеты магазина; [ручная приёмка](MANUAL_ACCEPTANCE.md) |
| Реклама | debug-блок demo-banner-yandex; release без рекламы по умолчанию; собственный ID и явное включение; отсутствие баннера на PIN, вводе/редактировании и деталях |

Ограничения первой версии: без облачной синхронизации, без подключения банков; баннерная реклама опциональна и по умолчанию в release отключена; ручные курсы и отдельно включаемое автоматическое обновление ЦБ РФ; приблизительное время фонового запуска; простой ориентир процентов вместо амортизационного графика; CSV вместо нативного XLSX, файл открывается в Excel; основная валюта фиксируется после начала учёта. До подтверждения всех аппаратных сценариев и подписи называть результат кандидатом, а не финальным опубликованным релизом.

## Финальная приёмка владельцем

1. Выбрать выпуск без рекламы (имеющийся проверенный release) либо настроить собственный блок РСЯ для `ru.epbloger.trachu`, собрать и проверить вариант с ним по [ADS.md](ADS.md). Не переносить ID другого продукта. Сверить сетевую активность и декларации фактического варианта.
2. Сохранить APK/AAB и QA-архив из указанного прогона. Подписать постоянным ключом по [SIGNING.md](SIGNING.md); проверить сертификат и контрольные суммы. Секреты не передавать в репозиторий или чат.
3. Выполнить [ручную приёмку](MANUAL_ACCEPTANCE.md) на физическом устройстве, включая системный выбор файлов, биометрию, виджеты, уведомления и сетевые запросы. Сверить окончательные скриншоты с подписанной версией.
4. Заполнить реальные сведения издателя, возрастную категорию и декларации, загрузить подписанный файл и материалы согласно [STORE_PUBLICATION.md](STORE_PUBLICATION.md), отправить на модерацию.
