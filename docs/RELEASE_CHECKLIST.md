# Проверка готовности

Состояние на момент интеграции: исходники пользовательских сценариев, ядро, Room, настройки, безопасность, резервная копия, CSV/PDF, валюты, виджет, фоновые задачи и документация добавлены. Это не подтверждение успешной сборки. Доказательства проверок — конкретные запуски GitHub Actions.

| Проверка | Критерий |
|---|---|
| JVM-тесты | суммы, перевод, возврат, валюты, бюджет, долг, расписание, CSV, backup |
| Android-тесты | атомарность Room, восстановление, миграция 1→2, реальная запись через Compose |
| Интерфейс | телефон и широкий экран, поворот, навигация, масштабирование |
| Сборка | assembleDebug, bundleRelease, lintDebug, тесты |
| Безопасность | неверный пароль и испорченная копия, PIN/биометрия на физическом устройстве |
| Файлы | SAF, CSV/PDF, фото чеков, перенос между устройствами |
| Сеть | реальный HTTPS-запрос ЦБ, отсутствие иных запросов |
| Фон | уведомления по разрешению, расписания, повторные запуски |
| Виджет | добавление на launcher, разные размеры, быстрый ввод, скрытие баланса |
| Публикация | подписанный артефакт, реальные скриншоты, анкеты магазина |

Ограничения первой версии: без облачной синхронизации, без подключения банков, без рекламы; ручной запрос курсов; приблизительное время фонового запуска; простой ориентир процентов вместо амортизационного графика; CSV вместо нативного XLSX, файл открывается в Excel; основная валюта фиксируется после начала учёта. До подтверждения всех аппаратных сценариев и подписи называть результат кандидатом, а не финальным опубликованным релизом.
