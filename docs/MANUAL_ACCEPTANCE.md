# Приёмка на устройстве перед публикацией

Проверки ниже дополняют CI: эмулятор не подтверждает работу физического датчика биометрии, стороннего файлового провайдера, лаунчера производителя, реальной рекламной сети и магазина. Используйте отдельную тестовую базу, не личную финансовую историю.

## Контрольный набор

Создать RUB-счёт с остатком 10 000,00 ₽ и USD-счёт с остатком 100,00 $. Установить курс 90,00 ₽/USD. Внести доход 1 000,00 ₽, расход 120,00 ₽ (80,00 продукты + 40,00 транспорт), возврат 20,00 ₽ из продуктов, перевод 900,00 ₽ на 10,00 USD. Ожидаемые остатки: 10 000,00 ₽ и 110,00 USD; общая оценка 19 900,00 ₽, доходы 1 000,00 ₽, расходы 100,00 ₽, результат 900,00 ₽. Смена курса на 95,00 ₽ меняет оценку баланса, но не суммы исторических записей.

## Пользовательские сценарии

| Сценарий | Действие и ожидаемый результат |
|---|---|
| Обзор, счета | Сверить контрольный набор; скрыть счёт из общего баланса и отчётов по отдельности, архивировать и вернуть. Исторические записи остаются доступны. |
| Запись и фильтры | Добавить расход с подкатегорией, двумя тегами и JPEG-чеком; отредактировать, найти по сумме, дате, тегу, счёту. Повторить расход: новая дата и идентификатор, без чека, до сохранения баланс не меняется. Отмена формы не меняет базу. |
| Возврат | Вернуть оставшуюся часть покупки и попытаться превысить исходную сумму. Полный возврат обнуляет расход категории; превышение отвергается. |
| Бюджет | Создать лимит, достигнуть 80%, 100%, превысить; проверить уведомления и отсутствие повторов одного порога. Сверить перенос положительного остатка на новом месяце. |
| Долг | Записать выдачу или получение, погашение с основной суммой и процентами. Основная сумма не попадает в обычные доходы/расходы. Проверить срок. |
| Цель | Пополнить, отменить часть накопления, проверить историю и срок. Виртуальная цель не создаёт лишнее движение средств. |
| Платежи | Выбрать будущий день календаря и создать разовую запись; провести вручную. Создать повтор с автопроведением, проверить наступивший срок и повторный запуск приложения. Не возникает дублей. |
| Курсы | Ручной и автоматический курс, история, отключение сети и автообновления. Ошибка сети не стирает сохранённые значения. |
| Отчёты | Переключить периоды, счета, сравнение, графики; сверить PDF с выбранным счётом, проверить обе стороны перевода. |
| Файлы | Экспорт CSV, открытие в таблицах, импорт поддерживаемой выписки дважды, PDF, зашифрованная копия. Восстановить на другом устройстве; неверный пароль, оборванный файл и конфликт не меняют существующие данные. Не удалять предыдущую проверенную копию до проверки нового файла; внешнее хранилище не гарантирует атомарную замену. |
| Защита | Включить PIN и биометрию; пять неверных попыток, смена PIN, блокировка по тайм-ауту, холодный запуск, переход из виджета. Финансовый интерфейс и баланс виджета скрыты до допуска. |
| Виджет | Добавить на домашний экран, изменить размер, включить баланс, затем PIN. Проверить быстрый ввод расхода/дохода и обновление после записи. |
| Доступность | Светлая/тёмная/системная тема, портрет/альбом, крупный шрифт и TalkBack. Все важные суммы, кнопки и состояния доступны; изменение темы не меняет записи. |
| Реклама | В release без ID баннера нет. С собственным ID проверить отказ, согласие и отзыв, переход в редактор/блокировку, потерю сети и возврат. Ни один финансовый сценарий не ждёт рекламу. Проверить трафик и актуальную декларацию SDK. |
| Обновление | Подписать один и тот же package постоянным ключом; увеличить versionCode после первой публикации; установить поверх предыдущей подписанной версии. Сверить контрольный набор, настройки и чеки. |

## Сравнительная оценка

На одном устройстве и одинаковом тестовом наборе измерить для ТРАЧУ., Orange Dog, Realbyte, Monefy и Cashew: число действий и время обычного расхода, разделения покупки, частичного возврата, поиска операции, изменения лимита и восстановления файла; отдельно фиксировать недоступные функции, стоимость/ограничения версии, ошибки и удобство крупного шрифта. Не засчитывать отсутствующую функцию как нулевое время. Публичные карточки в [PRODUCT_AUDIT.md](PRODUCT_AUDIT.md) не заменяют эти измерения.
