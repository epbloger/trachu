# Постоянная подпись релиза

В публичной CI-сборке нет ключа издателя. Debug APK подписан отладочным ключом; release APK и AAB по умолчанию не подписаны. Не публикуйте их как коммерческую сборку.

## Действия владельца

1. Если ключ ТРАЧУ. уже существует, используйте именно его. Иначе создайте отдельный постоянный ключ через Android Studio → Generate Signed Bundle / APK → Create new. Храните JKS вне D:\NP и вне репозиториев. Сделайте защищённую резервную копию; утрата ключа может сделать обновления невозможными. Для Google Play учитывайте правила Play App Signing и upload key; для RuStore сохраняйте совместимый ключ обновления.
2. В доверенном локальном окружении задайте переменные процесса `TRACHU_SIGNING_ENABLED=true`, `TRACHU_KEYSTORE_PATH` (абсолютный путь к JKS вне репозитория), `TRACHU_KEYSTORE_PASSWORD`, `TRACHU_KEY_ALIAS`, `TRACHU_KEY_PASSWORD`. Вводите секреты через защищённый ввод, не вставляйте их в команды, журналы, чат, GitHub Variables или исходники. Gradle не принимает неполную конфигурацию.
3. Из корня проекта выполните `gradle --no-daemon --no-configuration-cache assembleRelease bundleRelease`. Для монетизации дополнительно настройте собственный ID по [ADS.md](ADS.md). Без него релиз остаётся без коммерческих показов.
4. Проверьте `apksigner verify --verbose --print-certs` для release APK и `jarsigner -verify -verbose -certs` для AAB. Сравните SHA-256 сертификата с постоянным ключом, package `ru.epbloger.trachu`, versionCode и target SDK. APK и AAB находятся в `app/build/outputs/apk/release/` и `app/build/outputs/bundle/release/`.
5. Проверьте установку и обновление предыдущего подписанного релиза с сохранением данных на устройстве, сохраните контрольные суммы и commit. Перед загрузкой удалите переменные с паролями из окружения. Не меняйте ключ для обычного обновления, увеличивайте versionCode после первой публикации.

Не добавляйте ключ, пароль или секреты подписи в публичную CI-конфигурацию. В настоящий момент ключ владельца не предоставлен; инструкции и условная конфигурация не означают, что подпись уже выполнена.
