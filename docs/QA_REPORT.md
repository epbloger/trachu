Из [архива QA](https://github.com/epbloger/trachu/actions/runs/45800127139/artifacts/15106799925) извлечены XML: 13/13 на смартфоне API 36, 13/13 на планшете API 36; `qa/offline/result.txt` содержит PASS (42,50 ₽, ровно 4250 копеек в SQLite после холодного перезапуска, `Active default network: none` до и после). Задание отменено при отправке следующего коммита, API 26 не запущен. По [release APK](https://github.com/epbloger/trachu/actions/runs/45800127139/artifacts/15107326283) дополнительно сверены SHA-256 и все 8 ELF-библиотек: LOAD-сегменты и ZIP-смещения выровнены на 16 КиБ. Это статическая проверка, не испытание на физическом устройстве с 16-КиБ страницами.
- `55a0d20`: подтверждены новые сценарии восстановления после логического повреждения БД, старого зашифрованного архива с многомегабайтным чеком, гонки автопроведения и редактора, повтор операции, защита экспорта и дополнительные проверки API 33. Сценарий восстановления не гарантирует ремонт физически повреждённого файла SQLite. Черновики сохраняются в памяти при пересоздании Activity и блокировке; при полном завершении процесса Android несохранённые финансовые поля не восстанавливаются. Для отказа внешнего SAF-провайдера во время записи резервной копии нельзя обещать атомарную замену документа; прежнюю проверенную копию следует хранить отдельно.

## Что ещё не подтверждено

Это автоматически проверенный кандидат, не опубликованный магазинный релиз. Не проведён полный ручной цикл на физическом телефоне (реальная биометрия, виджет на launcher, SAF/чек, экспорт PDF и восстановление перенесённой копии, уведомления, трафик рекламного SDK). Рабочая монетизация требует собственного блока РСЯ и проверки деклараций; release по умолчанию без рекламы. Для магазинов требуется собственная релизная подпись и данные издателя. Полное превосходство над всеми конкурентами не доказано сравнительными пользовательскими тестами.
