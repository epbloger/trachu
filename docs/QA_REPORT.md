## Что ещё не подтверждено

Это автоматически проверенный кандидат, не опубликованный магазинный релиз. Не проведён полный ручной цикл на физическом телефоне (реальная биометрия, виджет на launcher, SAF/чек, экспорт PDF и восстановление перенесённой копии, уведомления, трафик рекламного SDK). Рабочая монетизация требует собственного блока РСЯ и проверки деклараций; release по умолчанию без рекламы. Для магазинов требуется собственная релизная подпись и данные издателя. Полное превосходство над всеми конкурентами не доказано сравнительными пользовательскими тестами.
